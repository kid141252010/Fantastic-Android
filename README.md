# Fantastic Android

[Fantastic](https://github.com/kid141252010/Fantastic) 的安卓客户端。在手机上搜歌、听歌、看歌词。

歌不在这个 App 里。先准备好自己的 Fantastic 服务器，打开后把地址填进去。能搜到什么、能播什么，取决于那台服务器和上面的账号。这个 App 不收集、也不发送网易云 Cookie。

Android 8.0 及以上可以安装。

## 亮点

- **一个搜索，三个音源。** QQ 音乐、Apple Music、网易云。歌曲、专辑、艺人、歌单都能点开听，从你点的那首开始。
- **歌词跟着唱。** 歌词画在手机上，唱到哪个字，哪个字亮。翻译和音译可以单独打开。对唱左右分开，背景人声单独显示。看歌词时屏幕保持亮着。
- **播放器拉上来就能用。** 底部是正在播放的小条。展开后有封面、歌词和接下来要播的歌，收起来音乐继续。再打开还是上次看的那一页。
- **资料库在手机上。** 可以建歌单和文件夹，收藏，导入和导出。想离线听，在菜单里下载，到「资料库 → 已下载」播放。下载的歌不会被播放缓存清掉。
- **资料库曲序与偏好。** 库内专辑只播放已保存的歌曲，按可信的碟号、曲号或专辑参考顺序排列；缺号保留未知，不把库内子集重新编号。已知在线总数大于库内曲目数时，列表尾部提供「显示完整专辑」，查看不会自动入库。歌曲、专辑和艺人的标题/最近添加排序分别记忆；「设置 → 资料库 → 显示音源来源」即时生效并在重启后保留。首页大标题随列表滚走，由浮动操作入口接管；点击底栏返回目标标签一级页，同标签搜索保留关键词和音源。
- **Apple Music 可以逛。** 「新发现」和「广播」用来找内容和电台。音质、空间音频和切歌方式在设置里选。

听过的在线歌曲会在手机里留一份，下次不用整首重下。缓存满了，先清最久没听、也没在用的。大小在设置里改。Apple Music 如果开了自动混音、交叉淡化，或者这首歌只能用网页播放，就继续在线播。

关掉再打开，歌、进度、待播顺序、随机和循环都还在，但不会自动接着播。

主页现在还是空的。找歌用底部的「搜索」。设置在主页右上角。

## 安装

每天构建的安装包在 [Nightly](https://github.com/kid141252010/Fantastic-Android/releases/tag/nightly)，文件名是 `fantastic-debug.apk`。这是预发布调试包，不是应用商店的正式版。签名固定，新包可以直接盖住旧包。

1. 装上并打开。
2. 主页右上角进入设置，填写 Fantastic 服务器地址，点「检查并保存服务器」。
3. 去「搜索」选音源，搜一首歌播放。

地址要是完整的 `http://` 或 `https://`，不要带账号和问号后面的参数。明文 HTTP 只建议在局域网里用。

## 本地字体打包

可选字体只从 Git 忽略的 `.work/local-am-fonts/assets/am-fonts/` 读取，不随源码或公开 CI 分发，也不在构建时下载。该目录需同时包含 `sf_pro_android_ui.ttf`、`sf_pro_rounded_android_ui.ttf`、`pingfang.ttc`、`hiragino_sans.ttc` 和 `apple_sd_gothic_neo.ttc`；现有其他语种字体可继续放在同一目录。

按 [Apple 的 CJK 字体建议](https://support.apple.com/zh-cn/guide/pages/tanfbd4156e/mac)，Android 10 及以上的界面和歌词共用 SF Pro 与 CJK 回退链：简体中文用苹方-简、台湾繁体用苹方-繁、香港和澳门用苹方-港，日文用无衬线 Hiragino Sans，韩文用 Apple SD Gothic Neo。应用语言决定汉字字形与回退顺序，字体保留各自真实字重，不套用 SF Pro 的可变轴。Android 8–9 的 CJK 继续使用系统字体。

本机构建显式传 `-PincludeLocalAmFonts=true`，缺少任一必需字体时停止构建；用 `-PincludeLocalAmFonts=false` 可构建纯系统字体包。TTC 在 APK 内不压缩，按集合共享只读映射和字体家族，避免按字号重复读取。
