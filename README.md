# Fantastic Android

[Fantastic](https://github.com/kid141252010/Fantastic) 的 Android 客户端，连接自己的服务器，在手机上搜歌、听歌、看歌词，支持 Android 8.0 及以上。

## 亮点

- **一个搜索，三个音源。** 在 QQ 音乐、Apple Music、网易云音乐中查找歌曲、专辑、艺人和歌单。
- **歌词跟着唱。** 支持逐词高亮、翻译、音译、对唱和背景人声，看歌词时屏幕保持亮着。
- **播放器随手展开。** 封面、歌词和待播清单集中在一处，收起后音乐继续；重开应用保留队列与进度，等待手动播放。
- **资料库与离线听。** 收藏音乐、建立歌单和文件夹、导入导出资料库，也可下载歌曲离线播放。
- **Apple Music 可以逛。** 通过「新发现」和「广播」寻找音乐与电台。

设置与日常操作见[使用指南](docs/usage.md)，可选字体与本地打包见[字体说明](docs/fonts.md)。

## 安装

1. 从 [Nightly](https://github.com/kid141252010/Fantastic-Android/releases/tag/nightly) 下载 `fantastic-debug.apk`，安装并打开。
2. 主页右上角进入设置，填写 Fantastic 服务器地址，点「检查并保存服务器」。
3. 去「搜索」选音源，搜一首歌播放。
