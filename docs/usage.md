# 使用指南

从主页右上角进入「设置」。播放偏好、字重和开关在选择或调整后立即保存；地区、歌词语言和字形在合法输入后自动保存。页面出现校验提示时，先按提示处理。

## 首次设置

1. 填写自己的「Fantastic 服务器地址」，使用完整的 `https://` 或 `http://` 地址，不带账号、查询参数或片段。
2. 点「检查并保存服务器」。本次 `/status` 验证成功后地址立即保存，地区信息和网易能力会在后台刷新；未通过时按页面提示核对地址和服务器状态。
3. 返回「搜索」，选音源、输入歌名并播放。

HTTP 为明文传输，只建议在局域网内使用。可搜索和播放的内容取决于服务器及其账号；网易云登录态由服务器管理员配置，App 不收集或发送 Cookie。

## Apple Music 地区

新安装默认使用 `ca`，已有地区选择会保留。在「设置 → 服务器 → Apple Music 地区（默认 ca）」输入地区代码，格式合法且符合已知 wrapper 支持列表时即自动保存；支持列表未知时只校验格式。设置页只显示缓存的 wrapper 支持地区，不显示 AM 目录；搜索框右侧的地区菜单可选择目录地区，两处共用同一选择。检查并保存新服务器后，当前草稿会按该服务器刷新后的支持列表重新校验，不会自动切换到其他地区。

检查服务器通过后，AM 目录和 wrapper 支持列表会在后台刷新，不影响服务器地址保存。刷新失败会保留对应列表上次成功的数据，支持标记不代表实时可用状态。

## 播放与下载

在「设置 → 播放」分别选择以下偏好，选择后立即保存：

| 入口 | 用法 |
| --- | --- |
| QQ 音乐音质 | 选择 Hi-Res、无损或其他可用格式。 |
| 网易云音质 | 选择 Hi-Res、无损或 MP3 音质。 |
| Apple Music · Wi-Fi 音质 | 单独选择 Wi-Fi 下的高效、高品质、无损或 Hi-Res 无损。 |
| Apple Music · 蜂窝网络音质 | 单独选择蜂窝网络下的音质，注意流量消耗。 |
| Apple Music · 全景声偏好 | 选择自动优先、始终优先或关闭全景声优先。 |
| Apple Music · 曲目切换 | 选择关闭、自动混音或交叉淡化；交叉淡化可用「−」「+」调节为 1–12 秒。 |

Apple Music 的下载音质在「设置 → 下载 → Apple Music · 下载音质」单独选择，不与 Wi-Fi、蜂窝播放音质混用。实际可播放的格式与音质还取决于音源、服务器和设备能力，可在播放器查看实际音质。

「设置 → 播放 → 播放缓存上限」可选 200 MB、500 MB、1 GB 或 5 GB，默认 500 MB。空间不足时先清理最久未播放且未在使用的播放缓存；手动下载的歌曲独立保留，不会被播放缓存清理。

## 歌词

展开播放器进入歌词页，点「歌词翻译与发音」入口，在弹出菜单中分别选择「显示翻译／隐藏翻译」和「显示发音／隐藏发音」。没有对应译文或音译时，该项不可用。

在「设置 → 歌词」填写「Apple Music 歌词语言」和「Apple Music 音译字形（script）」；默认分别为 `zh-Hans-CN` 和 `zh-Latn`，留空会恢复默认，合法输入即自动保存，非法输入不覆盖已保存值。字段最多 35 个字母、数字或连字符，结果取决于歌曲提供的歌词内容。

遇到歌词缺失、不同步或语言不符时，打开「设置 → 诊断 → 歌词诊断」，点按报告可复制版本与当前歌词状态，便于反馈。

## 字体字重

在「设置 → 字体字重」分别拖动「正文」「标题」「歌词」滑块，范围 100–900，数值越大越粗。调整即保存，重启后保留；每项旁的「恢复默认」只恢复该项。

字体的实际显示取决于安装包和系统可用字体。本地字体打包、字重映射与布局细节见[字体说明](fonts.md)。

## 资料库搜索

在「搜索」页的来源栏选择「资料库」，可离线搜索本机已保存的歌曲、艺人和专辑。歌曲按歌名、艺人名或专辑名匹配；已保存歌曲关联的艺人和专辑也会显示。点歌曲播放，点艺人打开详情，点专辑打开本机已保存曲目的专辑页。艺人详情及未缓存内容仍可能需要连接 Fantastic 服务器。

## 资料库

- **显示音源：** 在「设置 → 资料库 → 显示音源来源」打开或关闭歌曲、专辑的音源标记，修改立即生效并保留。
- **歌单和文件夹：** 在资料库首页或歌单列表点「新建歌单」加号；「更多操作」中可新建文件夹，进入文件夹后可新建子文件夹。通过歌曲菜单将歌曲加入本地歌单。
- **导入与导出：** 在资料库首页的「更多操作」中选择「导出资料库」保存文件，或「导入资料库」读取文件。导入可选「合并」或「替换」，替换会删除本机现有项目，操作前请先导出备份。
- **下载与离线听：** 在歌曲菜单选择下载，完成后从「资料库 → 已下载」播放；移除下载与移除资料库中的收藏是分开的操作。
